# IMAX 예매 오픈 알림 봇

CGV 특정 지점의 IMAX관(기본: 용산아이파크몰, 천호)에 새로운 상영 회차가 열리면 텔레그램으로 즉시 알려주는 감시 스크립트입니다.

CGV 공식 사이트가 실제로 사용하는 상영시간표 API를 그대로 조회하는 방식이라 별도의 크롤링/로그인 없이 동작합니다. **조회만 할 뿐 예매나 결제는 하지 않습니다.**

## 특징

- 용산아이파크몰 / 천호 IMAX관 기본 감시 (다른 지점도 설정으로 추가 가능)
- 특정 영화만 골라서 감시하거나, 전체 신규 IMAX 상영을 감시 가능
- 새 상영 회차가 감지되면 텔레그램으로 즉시 알림
- 이미 매진된 회차의 잔여좌석이 늘어나면(취소표 발생) 텔레그램으로 알림
- 별도 서버 없이 개인 PC에서 계속 실행하는 방식

## 요구사항

- Python 3.9 이상
- 텔레그램 계정 (알림 받을 채팅)

## 설치

```bash
git clone <이 저장소 주소>
cd imax-ticket
pip install -r requirements.txt
```

## 설정

### 1. 텔레그램 봇 만들기

1. 텔레그램에서 `@BotFather` 검색 후 대화 시작
2. `/newbot` 입력 → 봇 이름/아이디 설정 → **봇 토큰** 발급
3. 만든 봇을 텔레그램에서 검색해서 아무 메시지나 하나 전송 (예: "hi")
4. 브라우저에서 아래 주소 접속 (토큰 부분 교체):
   `https://api.telegram.org/bot<발급받은토큰>/getUpdates`
5. 응답 JSON에서 `"chat":{"id": 123456789, ...}` 의 숫자가 **chat_id**입니다.

### 2. 설정 파일 만들기

`config.example.yaml`을 복사해서 `config.yaml`로 만든 뒤 값을 채워주세요.

```bash
cp config.example.yaml config.yaml
```

```yaml
telegram:
  bot_token: "여기에 봇 토큰"
  chat_id: "여기에 chat_id"
```

> `config.yaml`은 `.gitignore`에 포함되어 있어 커밋되지 않습니다. 봇 토큰은 절대 저장소에 올리지 마세요.

나머지 옵션:

| 항목 | 설명 |
|---|---|
| `theaters` | 감시할 극장 목록. 기본값은 용산아이파크몰(0013), 천호(0199). 다른 CGV 지점을 추가하려면 사이트번호(siteNo)를 알아내야 합니다. |
| `screens` | 감시할 상영관 종류. 상영관 이름에 포함된 키워드로 매칭 (기본 `["IMAX"]`). `SCREENX`, `4DX` 등도 추가 가능. |
| `movies` | 감시할 영화 제목 키워드. 비워두면(`[]`) 모든 영화의 신규 IMAX 상영을 알려줌. |
| `cancel_check_interval_sec` | 취소표 확인 주기 (기본 8초). 이미 감지된 회차(active_dates)만 빠르게 재확인하는 거라 요청이 적어서 짧게 잡아도 비교적 안전합니다. |
| `full_scan_interval_sec` | 예매 가능한 전체 기간을 다시 훑어서 놓친 신규 상영(오픈)을 잡는 주기 (기본 30초). 날짜를 한 번에 다 훑지 않고 `full_scan_chunk_size`만큼씩 순환하며 훑습니다. |
| `full_scan_chunk_size` | 전체 재검사 한 번에 훑을 날짜 개수 (기본 10). 크게 잡으면 그 순간 요청이 몰려 차단 위험이 커지고 한 사이클이 길어져 취소표 감시가 지연됩니다. |

`cancel_check_interval_sec`, `full_scan_interval_sec`은 설정값 그대로 고정 주기로 도는 게 아니라, 매 회 약간의 랜덤 편차(취소표 감시 ±15%, 전체 재검사 ±35%)를 더해 정확히 N초마다 반복되는 기계적인 리듬을 피합니다. 요청 사이 딜레이도 같은 이유로 취소표 감시(0.4~1.2초)보다 전체 재검사(0.6~2.5초) 쪽 폭을 더 넓게 줍니다.

## 실행

```bash
python watcher.py
```

Windows에서는 `run.bat`을 더블클릭해도 됩니다.

- 처음 실행하면 현재 열려있는 상영 정보를 기준선으로만 저장하고(`state.json`), 알림은 보내지 않습니다.
- 그 이후부터 새로운 상영(=예매 오픈)이 감지되면 텔레그램 알림이 옵니다.
- 스크립트가 실행 중인 동안만 감시합니다. 터미널을 닫으면 감시가 멈춥니다.

## 알림 예시

**신규 상영(예매 오픈) 감지**
```
🎬 예매 오픈 감지!
극장: CGV 용산아이파크몰
영화: 듄: 파트3
상영관: IMAX관
일시: 2026.09.15 19:30
좌석: 450 / 450
```

**취소표 감지**
```
🎟 취소표 발생!
극장: CGV 용산아이파크몰
영화: 듄: 파트3
상영관: IMAX관
일시: 2026.09.15 19:30
잔여좌석: 3 / 450 (+3석)
```

## 주의사항

- 개인적인 예매 편의를 위한 조회용 도구입니다. 자동 결제/자동 예매 기능은 없습니다.
- CGV 사이트 구조가 바뀌면 API 응답 형식도 바뀔 수 있어 스크립트가 동작하지 않을 수 있습니다.
- `state.json`을 삭제하면 다음 실행 시 기준선을 다시 잡습니다 (기존 상영 전체가 "새로운 상영"으로 알림이 갈 수 있으니 주의).
- 과도하게 짧은 폴링 주기나 다수의 극장/조건을 동시에 감시하면 CGV 서버에 부담을 줄 수 있습니다. 상식적인 범위에서 사용해주세요.
- **취소표 알림은 좌석 번호를 특정하지 못합니다.** CGV는 개별 좌석 배치도를 보려면 로그인 또는 휴대폰 인증을 거치도록 막아놔서, 이 봇은 "잔여좌석 수가 늘었다"는 것까지만 감지합니다. 어느 좌석인지는 알림을 받은 뒤 직접 CGV에서 확인해야 합니다.
- `movies`를 비워서 전체 영화를 감시하면 취소표 감시 대상 회차 수가 많아져 매 폴링마다 호출하는 API 요청 수도 늘어납니다. 특정 영화만 지정하는 걸 권장합니다.
